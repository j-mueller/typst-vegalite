# Maintenance status

Updated 2026-09-10. Release preparation is separate from the implementation below.
The package version remains 0.1.1; no release has been published.

## Implemented

- **Typst compatibility:** ctxjs 0.5.0 with its matching native bytecode compiler,
  transition-based context initialization, and the current image API. The
  declared minimum compiler is Typst 0.13.0.
- **Reproducible build:** `./build.sh` checks and assembles the complete package
  through Nix. npm and Cargo dependencies are locked. Generated JavaScript,
  bytecode, and PDFs are excluded from source control. The artifact includes
  dependency license notices.
- **Dependency maintenance:** Vega 6.4.0, Vega-Lite 6.4.3, core-js-pure 3.50.0,
  and esbuild 0.28.2. Unused bundlers and polyfills are removed. The npm lockfile
  audit reports zero vulnerabilities, down from 18 at the initial audit.
- **Tests:** Node SVG golden, distinct/repeated charts, layered specifications,
  and invalid specifications. Integration tests import the assembled package
  using the published ctxjs runtime and compare its SVG against the same Node
  baseline. They cover defaults, mixed relative lengths, zoom, unbounded layout,
  expected failures, and the documented bar-chart example.
- **CI:** GitHub Actions builds and checks x86_64 and aarch64 Linux, tests the
  artifact with Typst 0.13.0 and 0.15.1, audits the npm lockfile, and uploads the
  built package. Actions are pinned to commit hashes.

The native compiler uses rquickjs 0.12.0 throughout its Cargo lockfile to match
ctxjs 0.5.0's bytecode format. The compiler source is pinned to upstream tag
`v0.5.0`, commit `c4c270035bac9a825564ca1257735c704ec8988a`. Integration tests
use the hash-pinned ctxjs 0.5.0 archive from Typst Universe, not an unpublished
runtime built from source.

## Verification and cache policy

The Nixpkgs pin is `d6524aaca2ff07876657ae2b323f24be4874944b`
(2026-09-08), with Typst 0.15.1 and Node.js 24.19.0. Both Linux systems evaluate.
Darwin is outside the requested scope.

Typst and Node.js runtime closures were verified directly against
`https://cache.nixos.org` on both Linux architectures: 8 and 62 paths respectively.
The Rust toolchain also comes from that cache. The maintainer accepts local
builds of the custom ctxjs compiler; no project binary cache is required.

The full build and integration checks run locally on x86_64 Linux. Forced
rebuilds of the JavaScript bundle and package reproduce the same Nix outputs.
Visual inspection confirms bar and line charts, zoom, and relative sizing.
aarch64 execution is assigned to the CI runner; local evaluation is not evidence of
execution on that architecture. The GitHub workflow must pass on both architectures before release.
